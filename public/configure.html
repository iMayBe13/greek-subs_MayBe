OpenSubtitles
Free account: 20 downloads a day.
Get your key
How to get the key
  1. Log in (or sign up) on opensubtitles.com, then open the API consumers page with the button above.
  2. Create a new consumer. Give it a unique name using only letters and digits.
  3. Leave “Allow anonymous downloads” ticked and save.
  4. Copy the key and paste it into the API key field.
  5. Also enter your opensubtitles.com username and password below: that is what gives you 20 downloads a day.

AI translation (optional)
Optional. When the sources in your link find no Greek subtitle, the add-on can translate the English one with AI, using your own free keys.
Get your key
How to get the key
  1. Sign up for “DeepL API Free” on deepl.com (it is a separate plan from the DeepL app).
  2. Open Account, then the API Keys tab.
  3. Copy the key and paste it into the field.

The free plan has a monthly character limit, shown in your account. One episode uses about 30,000 characters.

The screen may look slightly different.

Get your key
How to get the key
  1. Sign in to Google AI Studio with your Google account.
  2. Press “Create API key”.
  3. Copy the key and paste it into the field.

The free tier allows only a few episodes a day.

The screen may look slightly different.

How AI translation works

  • It runs only when no Greek subtitle exists on any source, and it uses your own keys.
  • The result is labelled AI (in the first line of the file and in the entry name) and may contain errors.
  • Finished translations are shared with other users of this add-on, and are removed when a human Greek subtitle appears.
  • The first time, you may see a “translation in progress” line instead of subtitles. Pick the subtitle again after a minute.
  • The file is made for one version of the video and can be out of sync with others. Use Stremio’s subtitle delay to fix it.
  • The English subtitles are sent to DeepL and Google to be translated. Google may use free-tier content to improve its products. For private use only.
